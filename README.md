# TV-Os

Launcher inmersivo al estilo Apple TV para televisores Android TV (objetivo inicial: Xiaomi MiTV-MOOQ0, Android 11), con un kit ADB para quitar software innecesario y mejorar la velocidad **sin root**.

- Decisiones y arquitectura: [`docs/decisiones.md`](docs/decisiones.md)
- Kit ADB (Fase 0 – diagnóstico): [`tools/adb-kit/`](tools/adb-kit/README.md)

## Estado
Fase 0: diagnóstico de solo lectura del dispositivo.
